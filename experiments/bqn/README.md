# BQN experiments

This directory is an optional scratchpad for trying BQN expressions and representations before a production decision.

Experiments may be incomplete, playful, comparative, or intentionally simplified. They are not production owners and production code must not import them.

Use synthetic data or public fixtures only. Never copy private household values here.

There is no required probe schema, catalog entry, preservation rule, or promotion ceremony. Keep a short note only when it helps explain an observed shape or failed assumption. Production adoption is a separate coherent change with ordinary tests and review.
