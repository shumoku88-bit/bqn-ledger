# Plans, handoffs, and design notes

This directory contains plans, handoffs, sketches, backlogs, and decisions from many stages of `bqn-ledger`.

The directory name does not make every file current or authoritative. Read individual documents for useful context, evidence, abandoned possibilities, and unresolved questions. Historical instructions, sequencing, status labels, and permission language do not limit present work.

When a task touches one of these documents:

- compare it with the current code, tests, fixtures, and user intent;
- keep the parts that still explain something useful;
- update, shorten, relocate, or delete stale material;
- record important discoveries and tradeoffs without turning them into a new approval process.

Useful present-day entrances are the root `README.md`, `AGENTS.md`, `TODO.md`, `docs/ARCHITECTURE.md`, and the code itself.

Git history preserves the longer inventory and earlier classifications.
